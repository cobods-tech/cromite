# Cromite 简体中文轻量界面 V1 设计规格

## 目标

以用户上传的三张浏览器截图作为布局和交互参考，重新设计 Cromite Android 首页、底部工具栏和菜单。保留截图中清晰的功能分区与操作逻辑，但不做逐像素复制。采用简体中文（中国大陆用语），必要技术术语可保留英文，例如 DNS、HTTPS、WebRTC。

## 视觉与交互方向

- 整体小巧、克制、整洁；让功能一眼可辨，不堆叠卡片或装饰。
- 首页采用“品牌标识 + 圆角搜索/地址框 + 圆形快捷网站图标”的清晰层级。
- 图标风格、线条粗细、尺寸、标签位置统一；避免混用不同风格的图标。
- 通过留白、对齐和稳定的间距建立秩序，不用大面积渐变、阴影或多余边框制造视觉效果。
- 常用功能优先；低频功能收纳，但不能删除。
- 浅色/深色主题均需完整设计；中文长文案不能截断，需适配系统字体缩放和不同屏幕宽度。
- 不改变 Chromium/Cromite 的网络、隐私、安全、渲染或设置默认行为。

## V1 页面范围

### 1. 首页 / 新标签页

- Cromite 品牌标识。
- 单一、醒目的圆角搜索/地址输入框。
- 圆形常用网站快捷入口，支持添加、删除、排序。
- 快捷入口采用统一图标容器和文字标签，避免复杂卡片。
- 不加入新闻流、广告或不必要的信息卡片。
- 保留 Chromium/Cromite 现有导航与新标签页核心行为。

### 2. 底部工具栏

保持单行、紧凑、固定的底部操作区，优先显示：
- 地址/搜索入口。
- 首页。
- 标签页切换及标签数量。
- 主菜单。

图标和触控区域保持一致；尽量复用 Chromium 现有工具栏与导航状态，不另造一套与浏览状态脱节的控件。

### 3. 主菜单

采用底部弹出式菜单，使用两页横向滑动布局：
- 每页为五列图标网格，图标在上、简体中文标签在下。
- 第一页放置最常用功能，例如书签、历史记录、下载、无痕模式、设置，以及经用户截图确认的其他高频入口。
- 第二页收纳其余低频功能。
- 页面之间支持左右滑动，并提供清晰但低干扰的页码/分页提示。
- 每个入口保持一致的图标尺寸、标签基线、间距和点击区域。
- 所有原有菜单动作都必须保留；隐藏或移至第二页不等于删除。
- 不得丢失原菜单动作、可访问性语义或无障碍标签。

### 4. 设置入口与分类

首层设置优先按用户任务组织：
- 基本设置
- 隐私与安全
- 网站设置
- 下载设置
- 高级设置

已有设置项保留；低频和实验性选项归入“高级设置”，不擅自改变其配置逻辑、默认值或安全行为。

## 本阶段不包含

- 不改动 Chromium 网络栈、渲染引擎、广告过滤或隐私保护逻辑。
- 不删除现有菜单动作或设置项。
- 不承诺网页正文、网站图片或媒体字幕自动翻译；本项目本阶段只处理浏览器自身 UI 中文化。
- 不在未验证构建环境和补丁兼容性前修改上游大范围源码。
- 不把尚未获得用户认可的视觉草图直接当作最终 UI 实现。

## 实施与验收

1. 对照 Chromium 153.0.8010.37 基线定位首页、工具栏、菜单和设置源码。
2. 先确认当前 Cromite 已有底部导航、新标签页和菜单补丁的实际效果，避免重复实现。
3. 以独立 Cromite patch 实现 UI 变化，并按 `build/cromite_patches_list.txt` 顺序集成。
4. 分阶段实现：先首页与菜单，再底部工具栏细节，最后设置入口重组。
5. 构建 APK 后检查浅色/深色主题、长中文文案、系统字体缩放、两页菜单滑动、标签页/无痕模式和全部原有菜单动作。
6. 每阶段记录修改文件、改动目的、风险与真实构建结果；未编译验证的补丁不得标记为完成。
