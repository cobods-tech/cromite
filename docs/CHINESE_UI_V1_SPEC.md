# Cromite 简体中文轻量界面 V1 设计规格

## 目标

以用户提供的移动浏览器截图为交互参考，重新设计 Cromite Android 的首页、底部工具栏、主菜单和设置入口。采用简体中文（中国大陆用语），保留必要的技术术语（例如 DNS、HTTPS、WebRTC）。

## 设计原则

- 小巧、简洁、低干扰；常用功能优先。
- 不常用功能默认不放在首屏菜单，统一收纳到“更多功能”或“高级设置”。
- 隐藏不等于删除：不得仅为简化界面而移除现有浏览器能力。
- 不改变现有设置项的语义、默认值或安全行为。
- 适配不同屏幕尺寸、系统字体缩放、浅色和深色主题。
- 中文文本不得被截断；图标、间距、触控区域保持一致。

## V1 页面范围

### 1. 首页 / 新标签页

- Cromite 品牌标识。
- 单一、醒目的搜索/地址输入框。
- 用户可管理的常用网站快捷入口（添加、删除、排序）。
- 不加入新闻流、广告或不必要的信息卡片。
- 保留 Chromium/Cromite 现有导航与新标签页核心行为。

### 2. 底部工具栏

优先显示：
- 地址/搜索输入入口。
- 首页。
- 标签页切换及标签数量。
- 主菜单。

尽量复用 Chromium 现有工具栏和导航状态，不另造一套与原浏览状态脱节的控件。

### 3. 主菜单

采用紧凑的底部弹出菜单，第一层只显示五个常用入口：
- 书签
- 历史记录
- 下载
- 无痕模式
- 设置

其他现有菜单动作收纳到“更多功能”二级页面。不得丢失原菜单动作、可访问性语义或无障碍标签。

### 4. 设置入口与分类

首层设置优先按用户任务组织：
- 基本设置
- 隐私与安全
- 网站设置
- 下载设置
- 高级设置

已有设置项保留；低频和实验性选项归入“高级设置”，不擅自改变其配置逻辑。

## 本阶段不包含

- 不改动 Chromium 网络栈、渲染引擎、广告过滤或隐私保护逻辑。
- 不删除现有菜单动作或设置项。
- 不承诺网页正文、网站图片或媒体字幕自动翻译；本项目本阶段只处理浏览器自身 UI 中文化。
- 不在未验证构建环境和补丁兼容性前修改上游大范围源码。

## 实施与验收

1. 先对照当前 Chromium 基线版本定位首页、工具栏、菜单和设置源码。
2. 以独立 Cromite patch 实现 UI 变化，并按 `build/cromite_patches_list.txt` 的顺序集成。
3. 先完成首页与菜单的最小可用改动，再处理工具栏与设置。
4. 构建 Android APK 后检查浅色/深色主题、长中文文案、系统字体缩放、标签页/无痕模式和原有菜单动作。
5. 每个阶段记录修改文件、改动目的、风险与构建结果。
